## Limitaciones
- Solo API 34 / emulador. Comportamiento de `LauncherApps` en OEM (Samsung) y en API 31/35 → T10.
- Android 14 bloquea lanzamientos desde segundo plano: las pruebas mantienen una Activity visible, como la tiene Focus cuando es el Home real.
- Tareas: las dos actividades de un mismo paquete comparten tarea, es comportamiento normal del sistema.
- La caché de iconos y la carga se prueban por fallback; no hay aún UI que los muestre (T05). Perfiles de trabajo/Espacio privado: no se consultan por diseño; su ausencia se comprobará con perfiles reales en T10.
- El contador de catálogo en Inicio es un marcador de depuración (nunca lista apps sin filtrar) que T05 sustituye.
